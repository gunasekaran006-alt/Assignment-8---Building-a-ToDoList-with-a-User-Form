# 📝 Modern To-Do List App

A simple, clean, and functional To-Do List web application that helps you stay organized and productive. Built using modern web technologies with a focus on user experience.

## ✨ Features
*   **Add Tasks:** Quickly add new items to your list.
*   **Edit Tasks:** Update existing tasks on the fly using a simple prompt.
*   **Mark as Complete:** Click on a task to strike it through when finished.
*   **Delete Tasks:** Remove unwanted items with a single click.
*   **Responsive Design:** Beautifully styled with a linear gradient background and Bootstrap 5 for all screen sizes.

## 🚀 Technologies Used
*   **HTML5** - Structure of the application.
*   **CSS3 & Bootstrap 5** - Custom gradients and responsive UI components.
*   **JavaScript (ES6+)** - Task logic (Add, Edit, Delete, Toggle).

## 🛠️ How to Run Locally
1.  Clone the repository:
    ```bash
    git clone https://github.com
    ```
2.  Open `index.html` in any modern web browser.
